# ZAKA Defensive Security Console

A Python terminal console for defensive security checks and
security-tool discovery.

## Requirements

- Python 3
- Git (for repository downloads)
- Kali Linux or another compatible Linux environment

## Run

```bash
python3 zakas.py
```

Some menu options may require additional system tools or
appropriate permissions.

## Safety

Use security checks only on systems you own or are authorized
to assess. Review downloaded repositories before running their code.
